# Client Handoff

## Entrega

El cliente recibe el código React/Vite, assets locales, configuración de build, documentación y `dist/` generado tras validar. PEPE LABS conserva aquí el proyecto conceptual; la propiedad y licencia de una entrega real deben definirse contractualmente.

## Cambios sencillos

Textos, navegación, tratamientos, beneficios, testimonios ficticios, perfiles e imágenes se modifican en `src/App.tsx` y `public/images/`. Colores y estilos base están en `src/index.css`.

## Requiere intervención técnica

Cambiar integraciones, activar formularios, modificar infraestructura, auto-hospedar fuentes, agregar analítica o migrar a un backend requiere revisión técnica y de privacidad.

## Activar datos reales

Antes de usar teléfono, correo o WhatsApp reales, obtener autorización, publicar aviso de privacidad, reemplazar datos ficticios y revisar cada acción. Un formulario real debe tener backend seguro, validación servidor, anti-spam, minimización, retención, consentimiento y control de acceso.

## Mantenimiento

Actualizar dependencias con revisión del lockfile, conservar backups de código y assets, validar el build antes de publicar y revisar HTTPS, dominio, certificados, permisos y logs. No guardar secretos en el repositorio.
