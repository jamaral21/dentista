# Changelog

## 0.1.0 - 2026-09-18

- Importación y auditoría del prototipo de Figma Make.
- Conservación de React, TypeScript, Vite y Tailwind CSS.
- Refactorización de navegación móvil, anclas y foco.
- Responsive y soporte para movimiento reducido.
- Fotografías locales para evitar dependencias remotas.
- Acciones de WhatsApp, llamada, correo y formulario convertidas en demostraciones sin transmisión.
- Metadata SEO conceptual y `noindex, nofollow`.
- Documentación de arquitectura, contenido, QA, despliegue, handoff y ADRs.
- Build estático preparado para Nginx.

## 0.2.0 - 2026-09-18

- Reorganización del proyecto en la raíz del repositorio.
- Referencias movidas a `references/` y eliminación del ZIP duplicado.
- Eliminación de Git LFS para imágenes pequeñas locales.
- ESLint real para React y TypeScript.
- División de la aplicación en layout, secciones, UI, contenido y tipos.
- Modal con trampa de foco y fondo inerte.
- Menú móvil con foco inicial y retorno de foco al cerrar con Escape.
- Eliminación de infraestructura exclusiva de Figma Make.
